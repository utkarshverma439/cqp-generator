# Start Here

Welcome, and thanks for taking this on. This folder is everything you need.

## Read in this order
1. **`01_Assignment_Brief.md`** — what to build, the rules, and how you're graded. *(Start here.)*
2. **`02_Domain_Primer.md`** — the domain in plain language. No prior knowledge assumed.
3. **`03_CQP_Field_and_Token_Reference.md`** — every template field and where its value comes from.
4. **`04_Frontend_Requirements.md`** — the minimal UI to ship.

## The clock
**48 hours** from when this pack was sent to you. Submit whatever you have at the deadline — partial, honest, and correct-where-it-counts beats finished-but-wrong. See Brief §7.

## Your materials
- `template/CQP_Template.docx` — the document you fill.
- `inputs/setA|setB|setC/` — three cells' worth of source documents.
- `reference_example/CQP_SetA_GOLD.docx` — the exact output expected for Set A. This is your definition of "correct."

## Deliver
- A runnable repo (generator + a basic web frontend).
- Your generated `.docx` for **Set A, B, and C**.
- `SOLUTION.md` — how to run it, your design, your assumptions, and where it breaks.

One piece of advice: **open every input file and the gold yourself, early.** The gold tells you the target; the inputs tell you what you're really up against. Budget time for the parts that aren't where you'd first look.
